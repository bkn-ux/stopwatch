# 해녀 조개 스탑워치

해녀가 무지개 조개를 들고 있는 스탑워치 모음입니다. 파일 하나로 동작하며 브라우저에서 바로 열면 됩니다.

| 파일 | 컨셉 |
|---|---|
| `timewatch-black.html` | 검은 바다, 진주빛 조개 |
| `timewatch-red.html` | 산호와 물고기가 있는 살아 있는 붉은 바닷속 |
| `timewatch-silver.html` | 은빛 UI, 대비와 접근성 중심 |
| `timewatch-gold.html` / `index.html` | 모든 요소를 담은 골드 버전 |
| `stopwatch*.html` | 초기 버전들 |

단축키: Space 시작/정지 · L 랩 · R 초기화
